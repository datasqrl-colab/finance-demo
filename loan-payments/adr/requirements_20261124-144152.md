Add a dev environment overlay `loan-payments-dev-package.json` for local development, layered on top of `loan-payments-shared-package.json`. Use exactly this content (copied from the reference file finance-demo/loan-payments/loan-payments-dev-package.json in another checkout):
{
  "script": { "config": { "environment": "test" } },
  "engines": {
    "vertx": {
      "config": {
        "auth": {
          "issuers": [
            {
              "issuer": "loan-payments-issuer",
              "audiences": ["loan-payments-api"],
              "keys": [{ "kty": "oct", "k": "bG9hbi1wYXltZW50cy10ZXN0LXNlY3JldC1zaWduaW5nLXN0cmluZw" }]
            }
          ]
        }
      }
    }
  }
}
It reads the catalog test data (environment "test") and uses a fixed dev JWT issuer, audience and HS256 key. Declare `dev` as an environment in run-tests.sh so `./run-tests.sh --compile --env dev` compiles the loan-payments sub-project with loan-payments-shared-package.json + loan-payments-dev-package.json. Document the dev package and how to run it locally in README.md.
